# Vehicle-Detection-CNN
Vehicle Detection using Resnet and VGG-16

### This project is aims to classify either if the image contains a vehicle or not.

### In this project we used a lot of data science techniques:
- Image Preprocessing
- Build a Convolutional Neural Network AArcheticture
- Transfer Learning using VGG 19 and ResNet 50
- Model Evaluation 
- Model Validation
- Deployment using Streamlit
